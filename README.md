# GitHub Pages 个人网站

这是一个无需安装任何工具的静态个人主页。

## 发布到 `github.io`

1. 在 GitHub 新建公开仓库，名称必须是 `你的 GitHub 用户名.github.io`。
2. 将本文件夹的内容推送到该仓库的 `main` 分支。
3. 在仓库 **Settings → Pages** 中，选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`，然后保存。
4. 等待一两分钟后，访问 `https://你的 GitHub 用户名.github.io`。

## 自定义内容

编辑 `index.html`：替换“你的名字”、简介、项目名称与链接、邮箱及社交账号。样式集中在 `style.css`。
